# Learner evidence

Write the reports that the lessons ask for in this directory. They are absent
from the starter so the coach cannot mark unfinished work complete. Use the
exact file names and `##` headings from each lesson.

Record concrete commands, outputs, decisions, and who made them. Keep what ran
separate from what you or an agent inferred. Do not include credentials,
personal data, or full environment dumps.

Runtime results such as the replay outcome, the restore drill, and the agent
replay come from the CI and Release workflow artifacts, not from these reports.
